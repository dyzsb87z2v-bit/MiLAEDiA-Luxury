6. INTERACTIVE RUG SELECTOR
==================================================

This is VERY IMPORTANT.

The rug selection interface must become a real 3D interactive component.

Each rug option should appear inside a refined 3D frame/card.

When the user selects another rug:

- the frame rotates in 3D
- current rug rotates away
- selected rug rotates into view
- image changes during/after the rotation
- the transition feels like physically turning a luxury object

Use:

perspective()
rotateY()
translateZ()
scale()

with smooth easing.

Example interaction:

Rug A
   ↓
rotateY(90deg)
   ↓
Rug B
   ↓
rotateY(0deg)

The frame itself should participate in the rotation.

DO NOT simply crossfade between images.

The user should feel that they are physically switching/turning a 3D rug display.
