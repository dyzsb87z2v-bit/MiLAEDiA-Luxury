4. REALISTIC 3D PARALLAX
==================================================

Add subtle 3D depth to the hero.

Mouse movement on desktop:

- city moves very slightly
- interior moves slightly
- rug moves slightly
- foreground elements move slightly more
- light/reflection moves subtly

Example depth hierarchy:

city: 0.15
architecture: 0.25
rug: 0.40
weaver: 0.55
foreground: 0.70

Movement must be extremely subtle.

This is a luxury fashion/gallery website.

Do NOT make it look like a gaming website.

No excessive shaking.
No aggressive zoom.
No spinning page.
No particle explosion.
No exaggerated 3D.

Use smooth interpolation / spring physics.

==================================================
5. TOUCH / MOBILE PARALLAX
==================================================

On mobile there is no mouse.

Use:

device orientation when permission is available
OR
very subtle touch/pointer movement

But the default mobile experience must remain stable even when motion sensors are unavailable.

Respect:

@media (prefers-reduced-motion: reduce)

When reduced motion is enabled:

- disable parallax
- disable large transforms
- keep only short opacity/fade transitions

==================================================
6. 3D RUG SELECTOR
==================================================

This is VERY IMPORTANT.

The rug selection area must become a real interactive 3D object.

I want a luxury 3D rug selector/card.

Example:

       ┌──────────────────┐
       │                  │
       │      RUG         │
       │                  │
       └──────────────────┘

When the user selects another rug:

The current rug should rotate around the Y axis and transition into the next rug.

Use a 3D flip/carousel effect.

CSS requirements:

perspective
transform-style: preserve-3d
backface-visibility: hidden
rotateY()

The transition should feel like physically turning a framed rug/product object.

NOT a basic horizontal image slider.

==================================================
7. RUG ROTATION INTERACTION
==================================================

Desktop:

- click next/previous
- optional drag interaction
- mouse movement can create a very subtle perspective tilt

Mobile:

- swipe left → next rug
- swipe right → previous rug
- tap next/previous controls
- tap the rug itself if appropriate

The rug should rotate in 3D during the transition.

Example:

current:
rotateY(0deg)

transition:
rotateY(90deg)

next:
rotateY(0deg)

Use easing such as:

cubic-bezier(0.22, 1, 0.36, 1)

Duration approximately:

700ms–1000ms

Do not make it too fast.
