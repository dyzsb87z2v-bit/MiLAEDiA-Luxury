1. PAGE 2 — COLLECTIONS
==================================================

The current mobile implementation shows the rug cards as very large vertical blocks.

This is NOT acceptable for mobile.

The supplied screenshot shows that the cards are too tall and force the user to scroll through huge fixed images.

DO NOT simply make the cards smaller.

Instead create a responsive collection presentation.

==================================================
2. MOBILE — 3D RUG CAROUSEL
==================================================

On mobile, convert the collection cards into a horizontal interactive carousel.

Only one primary rug should be visually dominant.

Example:

        previous
           ↓

      ┌─────────────┐
      │             │
      │    RUG      │
      │             │
      └─────────────┘
           ACTIVE

      next →

The user can:

- swipe left → next rug
- swipe right → previous rug
- tap navigation arrows
- tap the active card
- optionally use pagination dots

The carousel must NOT create horizontal page scrolling.

The horizontal movement must be contained inside the carousel.

==================================================
3. 3D CARD TRANSITION
==================================================

Do NOT use a basic fade or standard slider.

When changing rugs, create a subtle physical 3D rotation.

Current rug:

rotateY(0deg)

→

rotateY(90deg)

→

new rug:

rotateY(0deg)

The entire frame/card should participate in the transition.

Use:

perspective
transform-style: preserve-3d
rotateY
translateZ
scale
opacity

The effect should feel like turning a framed Persian rug artwork.

Animation:

600–900ms

Use a premium easing curve.

No bounce.

No excessive rotation.

No gaming-style effects.
